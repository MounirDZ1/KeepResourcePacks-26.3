# Keep Resource Packs

A client-side Fabric mod for Minecraft Java Edition 26.3.

Keep Resource Packs helps preserve your selected resource-pack list when a resource-pack reload fails.

## Compatibility

* **Minecraft:** Java Edition 26.3
* **Fabric Loader:** 0.19.5 or newer
* **Java:** 25 or newer
* **Mod version:** 1.0.1

## Installation

1. Install Fabric Loader for Minecraft 26.3.
2. Download `keep-resource-packs-1.0.1.jar` from the Releases section.
3. Place the JAR file in your Minecraft instance's `mods` folder.
4. Launch the game using your Fabric 26.3 profile.

## Important

This mod does not fix incompatible or broken resource packs. If a pack causes errors, disable it or find a compatible version.
